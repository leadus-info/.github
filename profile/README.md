# Leadus

**すべての知識を、すべての人へ。**

Leadusは、あらゆる分野の学問知識をオープンに集約・公開する学習サイトです。\
記事はMarkdownで書かれ、[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)のもとで[leadus.info](https://leadus.info/)に公開されています。誰でも記事の追加・修正・改善に参加できます。
